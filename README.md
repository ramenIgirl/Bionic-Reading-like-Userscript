# Bionic-Reading-like-Userscript
This simple userscript aims to create the [Bionic Reading](https://bionic-reading.com/br-about/) font formatting to every website you want.

This was made to be used when the browser extension doesn't work o is unusable. I use it for [Hermit](https://hermit.chimbori.com/) because it supports only userscripts. 

This is not perfect by anymean so feel free to modify this however you like.

(Ai was used in the making of this)
