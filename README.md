# Bionic Reading like Userscript
This simple userscript aims to create the [Bionic Reading](https://bionic-reading.com/br-about/) font formatting in every website you want.
This should help you read faster by bolding the first half of every word to guide your eyes better.

This was made to be used when the browser extension doesn't work o is unusable. I use it for [Hermit](https://hermit.chimbori.com/) because it supports only userscripts. 

This is not perfect by any mean so feel free to modify this however you like.
